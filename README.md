# 🛒 E-Commerce Customer Churn Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing customer churn in an e-commerce business using SQL and MySQL Workbench. The objective is to identify customer behavior patterns, understand the factors associated with churn, and generate insights that can help improve customer retention.

The project includes data cleaning, data transformation, SQL queries, and result analysis.

## 🎯 Objectives

- Clean and prepare the customer dataset for analysis.
- Handle missing values and inconsistent data.
- Standardize product categories, device types, and payment methods.
- Analyze customer churn patterns using SQL.
- Investigate customer tenure, order behavior, cashback, complaints, and other relevant factors.
- Analyze the relationship between customer returns, complaints, and churn.

## 🛠️ Tools and Technologies

- **MySQL Workbench** — SQL query execution and database management
- **SQL** — Data cleaning, transformation, aggregation, filtering, and joins
- **CSV** — Exporting query results
- **GitHub** — Project
